# Regular Expressions

Ruby scripts using Oniguruma regular expressions.

- `0-simply_match_school.rb`: matches `School`
- `1-repetition_token_0.rb`: matches `hbt{2,5}n`
- `2-repetition_token_1.rb`: matches `hbt?n`
- `3-repetition_token_2.rb`: matches `hbt+n`
- `4-repetition_token_3.rb`: matches `hbt*n`
- `5-beginning_and_end.rb`: matches `^h.n$`
- `6-phone_number.rb`: matches a 10 digit phone number
