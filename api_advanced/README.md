# api_advanced

Python scripts that query the Reddit API using the Requests module.

## 0-subs.py

Contains `number_of_subscribers(subreddit)`, a function that returns the total number of subscribers of a given subreddit. It returns 0 if the subreddit is invalid.

Usage:

    python3 0-main.py programming

Requirements: python3, requests module, PEP 8 style.
